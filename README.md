# Мой недельный план — Android
Автономный планировщик в WebView. Данные хранятся в памяти приложения. 
## Сборка
Загрузите содержимое папки проекта в корень репозитория GitHub. Вкладка Actions → Build Android APK → Run workflow. После завершения скачайте артефакт weekly-planner-apk, распакуйте ZIP и установите app-debug.apk.
Для автоматического запуска сборки можно загрузить файлы в ветку main.
Внимание: резервная копия данных перед переустановкой/удалением приложения обязательна. Debug APK предназначен для личного использования, не для публикации в Google Play.
